# Public analysis edition

This repository develops a completed course research topic into a reproducible analysis. It retains the question about AI-tool adoption and developer trust, while making the year-specific schema mapping, eligibility and calculations explicit.

The public implementation was reorganized and rechecked after the course. It is not the unchanged submitted notebook or report. The original submissions are retained privately. The public results are generated by the code in this repository from the documented survey snapshots.

The implementation separates neutral from negative trust, includes 2023 trust through its actual schema field, pairs answers within a respondent, and makes uncertainty and denominators visible. Claims about causes of trust erosion, precise concern frequencies, or priority over all previous research are not inferred from these descriptive tables.

The page contains no claim that a supervisor endorses this public revision. Original reports, slides, teaching templates, university logos, personal contact details and respondent-level data are outside this repository. Published literature is credited separately.
